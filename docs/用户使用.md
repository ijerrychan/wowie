# Wowie 用户使用指南

Wowie 是一个可扩展的桌面启动器，用于搜索并打开应用、文件、Windows 设置、网页和插件结果。本指南以 Windows 上的当前实现为准。

## 启动与退出

如果已有程序文件，运行 `wowie.exe`。从源码启动时，在仓库根目录执行：

```powershell
cargo run --locked
```

源码构建需要 Rust/Cargo 及 Windows 构建环境，具体见[开发文档](开发文档.md)和[构建与体积](构建与体积.md)。生成发布程序：

```powershell
cargo build --release --locked
.\target\release\wowie.exe
```

默认按 `Alt+Space` 呼出或隐藏搜索窗口。右键系统托盘中的 Wowie 图标，可以打开设置或退出程序。隐藏搜索窗口后程序仍在运行；需要完全关闭时使用托盘菜单的退出项。

## 第一次搜索

1. 按 `Alt+Space`，输入应用名，例如 `Notepad` 或电脑上已有应用的名称。
2. 按 `↑`、`↓` 选择结果，按 `Enter` 打开，也可以直接点击结果。
3. 右键结果或按 `Ctrl+M` 打开操作菜单。菜单会根据结果类型提供收藏、复制、打开所在目录等操作。
4. 按 `Esc` 关闭详情、退出当前搜索会话，或在默认搜索页隐藏窗口。

默认启用模糊搜索，不必总是输入完整名称。匹配强度、使用记录和设置中的排序共同影响结果位置；收藏可用于保留常用入口。结果下方的分类栏可缩小查看范围。

| 按键 | 操作 |
| --- | --- |
| `Alt+Space` | 呼出或隐藏窗口，可在设置中修改 |
| `↑` / `↓` | 切换选中的结果 |
| `Enter` | 打开结果或执行当前会话的动作 |
| `Tab` | 进入分类筛选，按界面底部提示操作 |
| `Ctrl+M` / `Shift+F10` | 打开所选结果的操作菜单 |
| `Esc` | 依次返回详情、会话或隐藏窗口 |

## 常用输入

以下使用默认触发词；如果已经修改设置，请使用自己的触发词。触发词后的空格属于示例的一部分。

| 输入示例 | 用途 |
| --- | --- |
| 应用名称 | 搜索开始菜单、桌面等已启用来源中的应用 |
| `1+2*3` | 计算表达式 |
| `e report` | 进入文件搜索，查找名称包含相关内容的文件 |
| `g wowie` | 使用默认 Google 快捷项搜索网页 |
| `w https://example.com` | 打开网站 |
| `> whoami` | 使用命令快捷项运行输入的命令 |
| `gt hello` | 使用 Google Translate 插件翻译，需安装并启用插件 |
| `天气` | 查找天气插件入口，需安装并启用插件 |

进入带触发词的搜索会话后，输入会交给对应引擎。翻译、天气等功能需要网络，具体要求见插件说明。命令快捷项会执行输入内容，按回车前先确认命令。

## 文件搜索与应用来源

在设置的搜索相关页面中，可启用文件搜索、修改默认触发词 `e`，并选择后端：

- `auto`：优先使用 Everything，不可用时回退到 Windows Search。
- `everything`：使用 Everything IPC，需要 Everything 正在运行。
- `windows-index`：使用 Windows Search，只能查到系统已建立索引的位置。

文件搜索与应用索引是不同入口。应用来源可以包含开始菜单、桌面、商店应用和额外索引目录；可配置索引扩展名，默认包括 `lnk`、`url` 和 `exe`。搜索不到应用时，先检查相应来源是否启用；搜索不到普通文件时，检查文件搜索后端及其索引范围。

## 个性化设置

从托盘菜单打开设置，可以调整全局快捷键、登录时启动、启动时显示、失去焦点时隐藏，以及主题、语言、字体、窗口尺寸和动画。搜索设置还提供模糊搜索、结果类别顺序和插件顺序等选项。

快捷项用于配置网页、命令或应用入口。例如默认 Google 快捷项使用 `g` 作为前缀、`https://www.google.com/search?q={query}` 作为模板，`{query}` 会替换为输入内容。设置前缀时避免与已有快捷项及插件触发词重复。

## 安装和管理插件

用户插件推荐安装到 `%LOCALAPPDATA%\Wowie\plugins`，每个插件一个子目录：

```text
%LOCALAPPDATA%\Wowie\plugins\my-plugin\
├── manifest.json
├── main.lua
└── icons\          （可选）
```

如果下载的是压缩包，解压后应确保 `manifest.json` 直接位于插件子目录中，避免多套一层目录。安装完成后完全退出并重新启动 Wowie，再到设置的插件页面确认启用状态，填写插件需要的偏好或 API key。

开发和便携运行时，程序也会扫描**当前工作目录**下的 `plugins`，它并不一定等于 `wowie.exe` 所在目录。避免在两个扫描位置安装相同 ID 的插件。发布程序时需按需附带仓库的 `plugins` 目录；插件不会自动编入可执行文件。

仓库目前提供天气、Google Translate 和 Steam Games 插件。插件设置中可以调整启用状态和排序；只有插件声明允许修改的命令才会提供触发词覆盖项。编写插件见[插件开发指南](插件开发.md)。

## 配置与排查

Windows 上的配置文件为 `%APPDATA%\wowie\config.json`，使用记录为同目录下的 `history.json`。手动修改前建议先备份；配置文件必须是合法 JSON。程序会监听配置变更，但更换插件脚本或清单后建议重启。

| 问题 | 检查方法 |
| --- | --- |
| 快捷键没有反应 | 确认程序仍在运行；在设置中改用未被其他程序占用的组合 |
| 文件搜索为空 | 确认已启用文件搜索，检查 Everything 是否运行或 Windows 索引是否包含目标位置 |
| 插件不出现 | 检查目录层级、`manifest.json`、启用状态；完全退出后重新启动 |
| 翻译或天气失败 | 检查网络及插件偏好；Google Translate 的详细说明见[插件 README](../plugins/google-translate/README.md) |
| 需要查看错误 | 在仓库根目录执行 `cargo run --locked`，查看终端中的 `plugin`、`query failed` 或 `launch failed` 信息 |

进一步报告问题时，附上复现输入、预期行为、实际行为及相关日志；分享日志或配置前移除 API key 等私人信息。
