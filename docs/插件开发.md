# 脚本插件（第一版）

当前插件实现暂时跳过文件搜索，优先验证“Launcher → Provider → Item → Action”的闭环。插件本地化由插件自己维护，暂不提供跨插件共享翻译目录。

## 目录与 Manifest

把插件放在项目目录的 `plugins/<id>/` 下，或用户数据目录的 `Wowie/plugins/<id>/` 下：

```json
{
  "id": "github",
  "name": "GitHub",
  "version": "0.1.0",
  "api_version": 1,
  "runtime": "lua",
  "entry_point": "main.lua",
  "keywords": ["gh", "github"],
  "permissions": ["network"]
}
```

`runtime` 是可执行文件名，`entry_point` 是相对于插件目录的脚本入口。因此 Lua、Python、Node 或自定义可执行程序都可以使用同一个协议；仓库里的 `example-utility` 使用 Python 只是为了开箱即用地演示协议。

## JSON Lines 协议

Launcher 每次查询启动一个短生命周期进程，向 stdin 写入一行：

```json
{"method":"query","query":"github react","api_version":1,"locale":"zh-CN"}
```

插件向 stdout 返回一行：

```json
{
  "items": [
    {
      "id": "facebook/react",
      "title": "facebook/react",
      "subtitle": "A JavaScript library for building user interfaces",
      "aliases": ["react"],
      "icon": {"type": "resource", "path": "icons/github.png"},
      "actions": [{"id": "open"}, {"id": "copy-url"}]
    }
  ]
}
```

Item 是 Launcher 的统一对象，不是插件私有 UI。`title`、`subtitle` 和 `actions` 已经足够支持当前的 Search / Execute；后续会在同一协议上增加 `view: list/detail/form` 和表单字段。

## 图标

Item 可以携带插件图标：

```json
"icon": {"type": "resource", "path": "icons/github.png"}
```

`resource` 路径相对于插件目录，当前支持 PNG；插件管理器会把它解析为插件资源文件。也可以复用系统图标：

```json
"icon": {"type": "system", "target": "C:\\Windows\\System32\\cmd.exe"}
```

`system` 的 target 会交给平台图标提供器处理，因此可以使用 `.exe`、文件路径或系统 Shell 目标。插件图标优先于默认的 launch target 图标，无法读取时会自动回退到系统默认图标。

## 当前边界

- 已支持：脚本插件发现、Manifest、动态 Search、统一 SearchResult、插件 Action 执行。
- 暂未支持：Form/List/Detail 导航、网络/文件权限隔离、插件热重载。
- 当前插件进程每次查询或执行重新启动，先保证协议简单和运行时可替换。
- 对需要增量索引的 Provider，后续应支持常驻进程模式。常驻进程将在 `initialize` 后持续处理 `index`、`update`、`query`、`execute`、`cancel` 和 `shutdown` 消息。
- 增量索引协议需要额外定义 `revision/cursor`、`upsert/remove` 和 `progress/ready`，避免 Launcher 与具体数据库或第三方同步机制耦合。
- 插件不要直接绘制 Slint UI，所有展示应通过 Item 和统一 View Primitive 表达。
- 查询请求包含 `locale` 和 `fallback_locale`。插件应按 `locale → 语言基础码 → fallback_locale` 查找 `locales/*.json`，代码中只使用 message key。`locale=system` 时由插件运行时自行读取系统语言。
