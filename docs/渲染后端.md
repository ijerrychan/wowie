# 渲染后端

Wowie 使用 Slint Winit 后端，`renderer` 配置项支持以下值：

| 配置值 | 渲染器 |
| --- | --- |
| `femtovg` | FemtoVG（OpenGL） |
| `femtovg-wgpu` | FemtoVG-WGPU（Direct3D / Vulkan / Metal） |
| `skia` | Skia（由平台选择图形后端） |
| `software` | Software（CPU 渲染） |

`skia-opengl` 仍作为兼容值保留。渲染器在启动窗口时选择；如果所选后端初始化失败，程序会自动回退到 `software`。
