# 优化待办

本文记录当前代码整理后仍未实现的优化项。已完成的配置原子写入、后台图标与详情图片加载、动作和 session 异步化、结果快照、分页去重、图像预算、排序一致性及 Windows 目录指纹优化不再重复列入。

优先级含义：

- **P0**：可能造成资源失控、数据丢失或系统集成行为错误，应优先处理。
- **P1**：明显影响性能、响应时间或长期运行稳定性。
- **P2**：维护性、可测试性和低频场景改进。

## P0：正确性与资源边界

- [x] **限制 ShellLink 文件读取并补齐损坏文件测试**（`src/platform/windows/shortcuts.rs`）。原生与回退路径都先拒绝超过 4 MiB 的文件，回退读取使用有界流并保留所有偏移/字符串边界检查；新增截断、ANSI、Unicode 和超大文件测试。验证：`cargo test --quiet`（2026-09-25）。

- [x] **让全局快捷键更新具备回滚语义**（`src/platform/windows.rs`）。更新值先做解析校验；新注册失败时恢复旧注册并记录冲突/恢复失败原因，避免配置刷新后快捷键静默失效。验证：`cargo test --quiet`、Windows 编译检查（2026-09-25）。

- [x] **统一后台任务调度与取消**（`src/utils/background.rs`、`src/ui/mod.rs`、`src/ui/details.rs`、`src/ui/results.rs`）。短生命周期 UI 任务统一进入 4 个 worker 和 128 个槽位的有界队列，队列满时拒绝新工作；取消 token 和查询/详情代次共同阻止过期任务继续处理或写回。长期监听线程仍保持独立生命周期。验证：`cargo test --quiet`（2026-09-25）。

- [x] **统一目录发现与指纹扫描的链接策略**（`src/providers/app/discovery.rs`、`src/utils/mod.rs`）。发现和指纹扫描共用 reparse/symbolic-link 判定；访问错误或路径消失时跳过该项，junction 不再递归或重复索引。验证：`cargo test --quiet`（2026-09-25）。

- [x] **为插件所有回调建立结构和内存上限**（`src/plugin.rs`、`docs/插件开发.md`）。初始化脚本/manifest、query/detail/execute/empty-state/icon 响应、storage JSON 均在转换为宿主模型前经过字节、深度、节点和字符串预算；结果、动作、详情块、表格和文本再按字段上限截断。验证：`cargo test --quiet`（2026-09-25）。

## P1：性能与长期运行稳定性

- [x] **将历史记录持久化移出锁和 UI/搜索路径**（`src/core/ranking.rs`）。历史状态在锁内生成快照，独立 writer 线程合并 150 ms 内的连续更新，并在退出事件循环后等待最新快照写入；`Ranker` 销毁时也会等待 writer 完成。验证：`writer_coalesces_snapshots_and_flushes_latest_on_drop`、`cargo test --quiet`、`cargo clippy --all-targets -- -D warnings`（2026-09-26）。

- [x] **为行为历史增加全局压缩策略**（`src/core/ranking.rs`）。加载历史时迁移并压缩，运行中每 64 次成功操作或碰到单项上限时压缩；行为记录保留 90 天、最多 2048 项，每项最多 32 个查询、全局最多 8192 个查询。空查询被清理，大小写变化合并，计数饱和累加。验证：`compaction_normalizes_queries_and_removes_empty_or_expired_entries`、`compaction_bounds_many_random_queries_and_items`、`cargo test --quiet`（2026-09-26）。

- [x] **为 Steam 插件建立图标索引并支持缓存刷新**（`plugins/steam-games/main.lua`）。刷新时集中扫描 `librarycache` 并建立 `appid -> icon` 索引，旧式图标和新版 AppID 子目录均可命中。用户可用 `refresh_minutes` 调整刷新间隔（默认 10 分钟，范围 1–1440 分钟）；定期重新发现安装项与图标，刷新失败时保留上一份有效缓存并至少间隔一分钟重试。验证：`steam_cache_indexes_icons_refreshes_and_keeps_last_good_snapshot`、`cargo test --quiet`（2026-09-26）。

- [x] **减少插件 fuzzy match 的重复分配**（`src/plugin.rs`、Lua API）。单项 API 复用匹配器与临时缓冲；新增 `wowie.fuzzy_filter`，一次转换查询并批量筛选多个标题/别名，Steam 插件已采用。1000 候选 × 100 查询的本机调试构建基准中，Rust 分配从每查询约 3898 次降至 8 次，P95 从 2.43 ms 降至 1.92 ms；数值仅用于同机相对比较，不含 Lua VM 的 C 侧分配。验证：`fuzzy_filter_matches_single_api_and_returns_candidate_indices`、`fuzzy_filter_benchmark`（忽略测试，显式运行）、`cargo test --quiet`（2026-09-26）。

- [x] **改进自定义目录监视的扫描策略**（`src/platform/windows.rs`、`src/platform.rs`）。Windows 改用递归目录变化通知，250 ms 安静期去抖（最长 2 秒），配置变化时重建句柄，并每 10 分钟完整指纹对账以覆盖丢失通知或暂时不可用的目录；空闲时只等待系统通知，不再每两秒递归扫描。非 Windows 保留两秒指纹回退。验证：`custom_directory_notification_covers_deep_changes` 在 1000 文件目录测得完整指纹扫描 24 ms、空闲等待一秒的进程 CPU 时间 0 ms、深层变化通知小于 1 ms；`cargo test --quiet`、Windows `cargo clippy --all-targets -- -D warnings`（2026-09-26）。

- [x] **为平台监听线程增加统一停止信号**（`src/platform.rs`、`src/platform/windows.rs`、`src/platform/windows/tray.rs`）。UI 持有共享停止信号，退出时唤醒并等待平台监听线程；快捷键和托盘循环改为等待 Windows 消息与停止事件，主题注册表监听改为异步可取消等待。目录、Shell、包目录监听均在退出时结束，并释放快捷键注册、通知句柄、Shell/WinRT 事件注册和托盘图标。验证：`platform_shutdown_joins_all_listeners_across_restarts`、Windows 集成测试 `platform_listeners_release_resources_across_restarts` 连续两次启动与退出均通过（2026-09-26）。

- [x] **合并 UI 中重复的搜索结果刷新流程**（`src/ui/mod.rs`、`src/ui/results.rs`）。查询变化与配置/provider 刷新共用 `apply_search_presentation`，集中处理空态、详情、搜索图标和媒体加载；它们与分页追加共用接收代次和共享结果快照的 `apply_result_snapshot`，统一模型发布、分类筛选和选择项处理。刷新保留仍可见的选中项，新查询从首项开始，分页维持当前索引。验证：`cargo test --quiet`、`cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`（2026-09-26）。

- [x] **建立可重复的性能基准**。增加 6 个可单独运行的忽略基准，覆盖初始应用索引、变化目录重扫、首次与连续查询、插件批量匹配、图标命中/未命中/LRU、历史快照落盘和有界队列压力；输出 P50/P95、进程线程峰值、队列峰值、缓存载荷字节和历史文件大小。测量数据及命令见 [`性能基准.md`](性能基准.md)。验证：6 个基准均在 Windows debug 测试配置运行通过（2026-09-29）。

- [x] **补充 Windows 系统集成回归矩阵**。新增 [`Windows回归检查.md`](Windows回归检查.md)，列出系统级自动化命令与 DPI/多显示器、主题、托盘退出、junction/符号链接、ACL 不可读配置和 renderer fallback 的手工清单；将截断 `.lnk` 与无效配置样本固定在 `tests/fixtures/windows/`，另有快捷键冲突回滚和监听器退出的忽略集成测试。验证：真实 Windows 上运行自动化用例（2026-09-29）；手工检查项留在清单供桌面回归执行。
