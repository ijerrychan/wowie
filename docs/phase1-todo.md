## Phase 1 验收标准

1. 启动程序后能看到搜索界面。
2. 输入应用名能返回排序后的应用结果。
3. 点击结果能启动对应应用。
4. 核心搜索逻辑有自动化测试。
5. Provider、Search Core、Result、Action、UI 之间边界清晰，后续可接入文件 Provider。
6. 输入 `> command` 可以通过默认 Shell 执行命令；配置型 URL 快捷指令可以打开网页。
7. 快捷指令、应用、网页和控制面板结果具有独立且可读的展示分类与位置文本。
8. 配置文件变更可以热加载，且高级字段显示开关不影响真实启动目标。
